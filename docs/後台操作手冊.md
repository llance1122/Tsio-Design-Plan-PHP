# 文章後台操作手冊

> 給發文的同學：如何在網站後台**發布、修改、刪除文章**。不需要任何程式知識，照著做即可。
>
> 回到 [README](../README.md)

## 帳號與權限

後台有兩種帳號：

| | 主帳號（老師，只有一個） | 副帳號（工讀生） |
|---|---|---|
| 發文、修改文章 | ✅ | ✅（所有文章都能改） |
| 刪除文章 | ✅ | ❌ |
| 新增、停用、啟用、刪除副帳號，幫人重設密碼 | ✅ | ❌ |
| 改自己的顯示名稱、密碼 | ✅ | ✅ |

文章清單上會顯示每篇是誰建立、誰最後修改（用「顯示名稱」）。

## 進入後台與登入

1. 打開瀏覽器，輸入後台網址：**`http://localhost:8000/admin/`**
2. 輸入**帳號**與**密碼**，按「登入」。
   - 第一次使用：主帳號的初始帳號、密碼都是 `admin`。
   - 工讀生：帳號與臨時密碼由老師給你。
3. **第一次登入（或拿到臨時密碼）時，會先要求設定新密碼**（至少 8 個字），設定完才能使用後台。
4. 登入成功後，上方是「發布新文章」的編輯畫面，最下面是「已發布文章」的清單。
   - **電腦**：左邊寫標題與內文，右邊的側欄放「發布文章」按鈕、摘要、日期、分類、海報，往下捲時側欄會固定在畫面右側。
   - **手機**：全部由上往下排成一欄，「發布文章」按鈕在海報欄位下面。

> 💡 關閉瀏覽器後需要重新登入。若被登出，重新輸入密碼即可。
> ⚠️ 連續輸錯密碼 5 次會被暫停登入 15 分鐘。

### 忘記密碼
- **工讀生**：請老師到「帳號管理」按你的「重設密碼」，老師會拿到一組臨時密碼給你，登入後再改成自己的密碼。
- **老師**：請管理網站的人在網站資料夾執行 `php tools/reset-admin.php`，主帳號會變回帳號 `admin`、密碼 `admin`，登入後馬上設定新密碼。工讀生的帳號不受影響。

## 帳號管理（老師）

上方選單的「**帳號管理**」：

- **我的帳號**：改帳號、顯示名稱；修改密碼（要先輸入目前的密碼，改完後其他裝置上的登入會被登出）。
- **新增副帳號**：填工讀生的帳號（英文、數字）與顯示名稱（例如「王小明」），按「新增」後畫面會顯示一組**臨時密碼**，把帳號與臨時密碼交給他。臨時密碼**只顯示這一次**，離開頁面就看不到了（忘了抄就按「重設密碼」再產生一組）。
- **重設密碼**：工讀生忘記密碼時用，會產生新的臨時密碼，他原本的登入會被登出。
- **停用／啟用**：暫時不讓工讀生登入時按「停用」（例如寒暑假）；之後按「啟用」就恢復。他寫過的文章不受影響，清單上仍看得到作者。
- **刪除**：確定不再使用的帳號才刪除，**無法復原**。他寫過的文章會保留，但作者會顯示為「（已刪除的帳號）」；想保留作者名字就用「停用」。
- **修改帳號／顯示名稱**：點帳號底下的「修改帳號／顯示名稱」。

工讀生的選單是「**我的帳號**」，只能改自己的顯示名稱與密碼。

## 發布一篇新文章

在「**發布新文章**」裡填寫：

### 基本欄位
| 欄位 | 說明 | 必填 |
|---|---|---|
| **標題** | 文章標題 | ✅ 必填 |
| **摘要／描述** | 一兩句話的簡介，會顯示在文章列表 | 選填 |
| **日期** | 例如 `2026 07 29` | 選填 |
| **分類／標籤** | 例如 `校友特稿` | 選填 |
| **海報圖** | 文章的封面／主圖，點「選擇檔案」上傳一張圖片 | 選填 |

### 撰寫內文（重點）
內文編輯區的用法跟 Word 差不多：直接打字，按 Enter 換段落。上方工具列可以套用格式，先把游標放在那一段（或選取文字），再按按鈕：

| 按鈕 | 作用 |
|---|---|
| **B** / *I* / U / ~~S~~ | 粗體、斜體、底線、刪除線（選取文字後按；也可以用 Ctrl+B、Ctrl+I、Ctrl+U） |
| **標題** / **小標題** | 把這一段變成標題（字比較大，前面會空一段距離）；再按一次變回一般內文 |
| **內文** | 變回一般段落 |
| **引言** | 引用別人說的話，左邊會有一條直線 |
| **• 清單** / **1. 清單** | 項目清單、編號清單；在空白的清單項目再按一次 Enter 就會結束清單 |
| **連結** | 先選取文字，按下後輸入網址（站外連結在前台會另開分頁） |
| **取消連結** | 把選取文字的連結拿掉 |
| **圖片** | 在游標位置插入圖片，選檔後自動上傳（一樣會自動縮圖） |
| **分隔線** | 插入一條橫線 |
| **清除格式** | 把選取文字的粗體、斜體等格式拿掉 |
| **</> HTML** | 切換成 HTML 原始碼，可以直接改；再按一次切回來 |

游標所在的格式會在工具列上反白（例如游標在標題裡，「標題」按鈕會變黑），看得出現在是什麼格式。

> 📝 **從 Word 或網頁複製貼上**：文字、粗體、清單、連結會保留，字型、顏色、字級會自動拿掉，套用網站統一的樣式。

> 🎬 **嵌入 YouTube 影片或 Google 地圖**：按「HTML」切換成原始碼，把 YouTube「分享 → 嵌入」或 Google 地圖「分享 → 嵌入地圖」給的 `<iframe …>` 那段貼進去即可。
>
> 為了安全，存檔時只會保留排版用的標籤（標題、段落、清單、連結、圖片、表格、引言、YouTube／Google 地圖），其他的（例如 `<script>`、`style="…"` 顏色設定）會自動拿掉。

### 上架／下架時間（選填）
側欄的「**上架時間**」「**下架時間**」可以讓文章在指定的時間自動出現或消失，時間到了前台會自己切換，不用再回來操作：

| 想要的效果 | 上架時間 | 下架時間 |
|---|---|---|
| 存檔後馬上出現、一直留著（預設） | 留空 | 留空 |
| 先寫好，**10/5 早上 9 點**才出現 | 2026-10-05 09:00 | 留空 |
| 活動結束後自動拿掉 | 留空 | 活動結束的時間 |
| 只在某段期間出現 | 開始時間 | 結束時間 |

- 還沒到上架時間、或已經過了下架時間的文章，前台的文章列表、首頁都看不到，直接打網址也會顯示「找不到這篇文章」。
- 下方「已發布文章」清單會標示每篇的狀態：**上架中**（綠）、**排程中**（黃，附上架時間）、**已下架**（灰）。
- 想讓已下架的文章重新出現：按「編輯」，把下架時間清空（或改晚）再存檔。
- 排程中或已下架的文章，可以按側欄的「**預覽**」（或在清單點標題）看前台的樣子，只有登入後台的人看得到。

### 送出
確認都填好後，按「**發布文章**」（電腦在右邊側欄最上面，手機在內文與海報下面）。
成功會出現「發布成功！」，新文章立刻出現在下方清單最上面，網站前台也馬上看得到。

## 修改一篇已發布的文章

1. 在下方「已發布文章」清單，找到要改的那篇，點它右邊的「**編輯**」。
2. 該篇的所有內容會自動帶入上方的編輯畫面（標題、內文都會出現）。側欄的「預覽」可以另開分頁看前台的樣子（還沒上架的文章也看得到）。
3. 直接修改你要改的地方。
4. **海報**：如果不想換圖，就不要選新檔，原本的圖會保留；想換就上傳新的。
5. 改完按「**更新文章**」。出現「已更新！」就完成了。

> 💡 修改文章**不會改變它的網址**，原本分享出去的連結仍然有效。
> 想放棄修改，按「取消編輯」回到發布新文章模式。

## 刪除一篇文章（只有老師）

1. 在清單找到那篇，點右邊的「**刪除**」。
2. 會跳出確認視窗，按「確定」。

> ⚠️ **刪除無法復原**，連同它的海報圖與內文裡的圖片也會一起刪掉，刪之前請確認。

## 小提醒

- **文章列表的排序**依上架時間（沒設定就用發布時間），排程的文章到點上架時會排在最前面。
- **還沒存檔就離開頁面**，瀏覽器會跳出提醒，避免寫到一半的內容不見。
- **海報圖建議用橫式**：文章卡片與內頁大圖是橫式比例，橫式圖片顯示效果最好。
- **沒有上傳海報**也可以發文，系統會用一張預設的封面圖。
- **不用自己先縮圖**：上傳後系統會自動縮到 1920 像素寬並轉成 webp，手機拍的照片也會自動轉正。上限 8MB。
- **登出**：右上角有「登出」按鈕，在公用電腦操作完記得登出。
